# Add a number line

The Number Line design element provides students with a graphical representation of number ordering. 

Why add a number line to worksheets?

- At a very basic level, a pre-numbered line is useful as a counting aid.

- Number lines can help students understand that numbers have a position in space, establishing distance and direction between numbers.

- Number lines can be very helpful for students first learning integers and how negative numbers are ordered.

**To Add This Design Element**: Select Number Line from the drop-down list of Design Elements located on the main ribbon to insert a number line below the currently selected element in the document.

## Set the number of units on the number line

1. Select Units in the left-hand the options pane.

2. Type a new value in the input field, or use the up and down arrows. Valid range is 1 to 20.

## Set the start point

1. Select Start Point in the left-hand options pane.

2. Type a new value in the input field, or use the up and down arrows. Valid range is -10000 to 10000.

## Set the increment

1. Select Increment the in left-hand options pane.

2. Type a new value in the input field, or use the up and down arrows. Valid range is 1 to 1000.

!!! tip
    For a worksheet that shows a number line from -10 to 10, enter 20 Units, set Start Point to -10, and enter 1 for Increment.

## Show the unit numbers

In the left-hand options pane, check or uncheck the box for Show Unit Numbers to show or hide the unit numbers.

## Change the labels font

1. Select Labels Font in the left-hand options pane, and press the ellipsis button (...) to display the font selection dialog.

2. Select the preferred font name, style, and size.

3. Click OK to close the dialog and apply the selected font.

## Change the labels color

1. Select Labels Color in the left-hand options pane, and press the ellipsis button (...) to display the color selection dialog.

2. Choose the color you like from the Basic or Web tabs.

3. Click OK to save your choice and apply the new color.

## Change the line color

1. Select Line Color in the left-hand options pane, and press the ellipsis button (...) to display the color selection dialog.

2. Choose the color you like from the Basic or Web tabs.

3. Click OK to save your choice and apply the new color.

## Change the line width

1. Select Line Width in the left-hand options pane.

2. Type a new value in the input field, or use the up and down arrows. Valid range is 1 to 4.

## Adjust the padding

This option sets the padding (extra white space) around the item in 100ths of an inch (25 = 1/4 inch, 40 = 1 cm).

1. Select Padding in the left-hand options pane to display all of the sides that can be customized.

2. Select a side (All, Left, Right, Top, Bottom) to change the value for that side.

3. Type a new value in the input field, or use the up and down arrows to increase or decrease the value. Valid range: 0 to 100.

!!! tip
    Change only All to update the four sides to the same value. If All shows -1, one or more of the sides has a different value.
