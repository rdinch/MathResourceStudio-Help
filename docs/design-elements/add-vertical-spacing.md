# Add vertical spacing

<p style="color: red; font-weight: bold;">Under Review</p>

The Vertical Spacing element inserts empty vertical space in the document. You can use this design element to control the space between design elements and sets of exercises.

**To Add This Design Element**: Select Vertical Spacing from the drop-down list of Design Elements located on the main ribbon to insert blank space below the currently selected element in the document.

## Change the height

Sets the height of the vertical spacing in 100ths of an inch (25 = 1/4 inch, 40 = 1cm).

1. Select Height in the left-hand options pane.

2. Type a new value in the input field, or use the up and down arrows. Valid range is 1 to 100.
