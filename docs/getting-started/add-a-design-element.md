# Add a Design Element

## To a New Document

1. Open Math Resource Studio.

2. Click New to start a new blank document.

3. At the top of the program window locate Design Elements in the Design area of the main ribbon.

4. Click the down arrow for Design Elements to display the list of elements. Select the one you want to use to add it to the document.

5. To add additional design elements, click the down arrow for Design Elements and select again from the list.

## To an Existing Document

When adding a design element to a document that already has exercise sets and design elements, the newly selected design element will be placed after the active set of questions or design element.

!!! tip
    To locate the active item, look for the light blue border around a set of questions or a design element.

1. With an existing document open and displayed in the Math program, click once on an exercise set question or design element on the page so it becomes the active object on the page.

2. At the top of the program window locate Design Elements in the Design area of the main ribbon.

3. Click the down arrow for Design Elements to display the list of elements. Select the one you want to use to add it to the document.

4. To add additional design elements, click the down arrow for Design Elements and select again from the list.
