# Add an Exercise Set

## To a New Document

1. Open Math Resource Studio. Click the New tile to start a new blank worksheet.

2. When the new blank worksheet appears, locate the left pane labeled Exercise Sets. Expand a topic by clicking on the greater than sign (>) to display the exercise sets available for that topic.

3. Click once on an exercise set name to add a set of that type of questions to the blank worksheet.

4. To add another exercise set to that same document, click again on the name of any exercise set.

5. Once you have added all of the exercise sets you want, you can customize, edit, save and print your document.

## To an Existing Document

When adding an exercise set to a document that already has exercise sets and design elements, the newly selected exercise set will be placed after the active set of questions or design element.

!!! tip
    To locate the active item, look for the light blue border around a set of questions or a design element.

1. With an existing document open and displayed in the Math program, click once on an exercise set question or design element on the page so it becomes the active item on the page.

2. Locate the left pane labeled Exercise Sets. Expand a topic by clicking on the greater than sign (>) to display the exercise sets available for that topic.

3. Click once on an exercise set name to add a set of that type of questions to the worksheet.

4. Once you have added all of the exercise sets you want, you can customize, edit, save and print your document.
