# Navigation Bar at the Top - Serial and Version Number at the Bottom

Just above an open worksheet or answer sheet document is a navigation bar made up of navigation arrows and - in the case of the worksheet - a Go To feature.

## Navigation

The navigation arrows provide a way to move from page to page of a multi-page worksheet or answer sheet. And because a multi-page worksheet can have many more pages than an answer sheet, there is a Go To feature.

Click a navigation arrow to move to the first page, next page, previous page, or last page, or use the following keyboard shortcuts (???????? what are these????):

- Alt + Home - moves to the first page

- Alt + End - moves to the last page

- Alt + Left Arrow - moves to the previous page

- Alt + Right Arrow - moves to the next page

When working with a multi-page worksheet, enter the page number in the Go To box and click the arrow next to it, or press Enter, to navigate to that page.

## Serial Number (SN)

When a math document is created a unique serial number is automatically generated based on the number of seconds that have passed since 2015. If needed, the serial number can be manually adjusted by clicking the up arrow by the number.

Serial numbers can be added to a header or footer of worksheets or answer sheets by using the tag `<sn>` in a text field.

## Version Number

The Version Number provides a way to quickly identify the printed worksheet and answer sheet pages when printing variations of the same math document. The version number can be manually adjusted by clicking the up or down arrow by Version number at the bottom of the program window, or by using Regenerate Between Copies when printing the document.

Version numbers can be added to a header or footer of worksheets or answer sheets by using the tag `<v>` in a text field.
