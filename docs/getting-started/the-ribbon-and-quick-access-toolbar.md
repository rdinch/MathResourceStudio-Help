# The Ribbon and Quick Access Toolbar

## The Ribbon

The ribbon is the main command bar at the top of the Worksheet View tab and Answer Sheet View tab. These command bars contain the main commands to help you edit and format your worksheets or answer sheets. 

By default, the ribbon displays both icons and their labels. To increase the viewing area of the worksheet or answer sheet in the program window, select Simplified Layout on the far right of the program window just above the ribbon. Simplified View displays smaller icons in a narrow line across the window; if your screen is narrow, some commands will be accessed only by a drop-down arrow.

## The Quick Access Toolbar

The Quick Access Toolbar is a small, customizable toolbar that sits near the top left corner of the program window. It gives you one-click access to tools like New, Save, Open and program Settings no matter which tab you are using.

Click the down arrow at the end of the quick access toolbar for command customization options as well as the display option to Show Above or Show Below the ribbon, and the option to Minimize the Ribbon (leaving only the quick access toolbar on display).

!!! note
    When using the Simplified View for the ribbon, the Quick Access Toolbar will be moved to show above the ribbon.
